Frequently Asked Questions

1. Why choose a 4-socket R840 over a 2-socket R740 if they both fit in 2U?

While both occupy 2U of space, the Dell PowerEdge R840 Server provides double the processor density and significantly higher memory capacity (48 DIMMs vs 24 DIMMs). The R840 Rack Server is designed for workloads that are compute-bound or require massive in-memory datasets that a 2-socket system simply cannot accommodate.

2. Can the R840 run with only two processors?

Yes, the PowerEdge R840 can be configured with only two processors. However, this will limit the available PCIe lanes and half of the DIMM slots will be inactive, as those resources are hard-wired to the specific CPU sockets.

3. What are the UPI links, and why do they matter?

Ultra Path Interconnect (UPI) links are the high-speed pathways that allow the four processors in the Dell PowerEdge R840 Server to communicate with each other. The R840 supports up to 3 UPI links per CPU, reducing latency when one processor needs to access data held in the memory controller of another processor.

4. What is the "thermal wall" for 256GB LRDIMMs?

The "thermal wall" refers to the heat threshold reached when using high-density 256GB LRDIMMs. In a Dell PowerEdge R840 Server, using these modules may require the system to operate in a specific temperature-controlled environment or require the fans to run at higher duty cycles to prevent throttling.

5. Can I mix RDIMMs and LRDIMMs in the R840?

No. You cannot mix different types of memory (RDIMM and LRDIMM) within the same R840 Server. All installed DIMMs must be of the same type to ensure system stability and successful booting.

6. Does the R840 support 12Gbps SAS drives?

Yes, the Dell PowerEdge R840 Rack Server fully supports 12Gbps SAS interfaces, provided you use a compatible RAID controller like the PERC H740P or H730P.

7. Is the R840 capable of training Large Language Models?

The Dell PowerEdge R840 Server can be used for training smaller models or fine-tuning existing LLMs. While it is a powerhouse, extremely large-scale LLM training is usually handled by multi-node clusters with specialized GPU accelerators. However, the R840 is excellent for the inference stage.

8. How many GPUs can I physically install?

The Dell EMC PowerEdge R840 Server supports up to 2 double-width GPUs or up to 6 single-width GPUs, depending on the PCIe riser configuration and power budget.

9. Which NVIDIA GPUs are most commonly used in the R840 for AI?

The NVIDIA T4 and NVIDIA V100 are frequently paired with the Dell PowerEdge R840 Server for AI inference and data analytics workloads due to their balance of performance and thermal requirements.

10. How do I access the server if the network port is down?

You can access the R840 Rack Server via the front-panel micro-USB port using the iDRAC Direct feature, or via the Quick Sync 2 wireless module if configured, allowing for local management without a standard network connection.

11. What is the "System Lockdown" mode?

System Lockdown is a security feature within iDRAC9 that prevents any changes to the BIOS, iDRAC, or firmware settings. It is a vital tool for the Dell PowerEdge R840 Server in high-security environments to prevent "insider threat" configurations.

12. How do I find the hard drive serial number without opening the server?

The serial numbers (and other telemetry) for all drives in the Dell PowerEdge R840 Server can be viewed through the iDRAC web interface under the "Storage" tab, or via the OpenManage command-line interface.

13. Is the R840 quiet enough for an office?

Generally, no. The Dell PowerEdge R840 Server is a high-performance enterprise machine. Because it packs four CPUs into a 2U space, the fans spin at high RPMs to maintain cooling. It is designed for installation in a climate-controlled data center or a sound-dampened server room.
